CRISP-DM Phase Experimental Component Implementation & Protocol Detail
1. Business Understanding Productivity Score Prediction Predict student academic productivity from lifestyle, academic, and behavioral metrics using Multiple Linear Regression.
2. Data Understanding Exploratory Data Analysis (EDA) 16,000 complete records with zero missing values. Pairwise correlation heatmap reveals strong correlations with study hours, focus, sleep, phone, stress, and attendance.
3. Data Preparation Partition & Dummy Encoding 80% Train (12,800 rows) / 20% Test (3,200 rows) with fixed random_state=42. Categorical gender encoded via dummy variables (Female as reference).
4. Modeling 6 Feature Selection Strategies Pearson Correlation, Forward SFS, LassoCV, RFECV, Exhaustive Best Subset Search (Gram matrix CV), and Baseline OLS. Feature ranking strictly fitted on training split only.
5. Evaluation Parsimony & 95% Prediction Interval Identified per-algorithm optimal sweet spots: LassoCV k=6, Forward SFS k=7, Pearson k=8 — all achieving Test RMSE ≈ 0.0029, R² = 1.0000. Best-case sweet spot is LassoCV at k=6. Calculated exact 95% Prediction Interval: ŷ ± t_{crit} × √(s²(1 + x₀ᵀ(XᵀX)⁻¹x₀)) with 100.0% test coverage.
6. Deployment GitHub Pages & Interactive Predictor Pure Vanilla HTML5/CSS/JS web deployment with real-time interactive predictor and Chart.js visualizations. Model serialized as student_productivity_model.pkl.
